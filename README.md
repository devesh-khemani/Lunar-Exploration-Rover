# Lunar Exploration Rover - Sensor Integration Logbook

This logbook documents my contribution to a 5-person team project to design,
build, and demonstrate a live lunar exploration rover, completed May–June 2024.

[Download Logbook PDF](group_project_y1-compressed.pdf)

## My contributions documented here:
- Analog front-end design and LTspice simulation for a 950nm infrared sensor and
  a Hall-effect magnetic sensor
- Active filtering design to reject 100 Hz ambient lighting interference
- MCP6022 op-amp gain stage design to resolve weak magnetic field signals
- Oscilloscope-based verification of analog signal margins
- Integration of sensor hardware with ARM Cortex-M0 firmware, including C++
  sensor driver development

## Project context
Developed as part of a 5-person team, culminating in a live rover demonstration.
Milestone technical presentations were delivered throughout the project alongside
the hardware/firmware build.

## Tools & Technologies
LTspice · C++ · ARM Cortex-M0 · Oscilloscope
